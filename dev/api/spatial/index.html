Spatial model

Landscape and dispersal

PowderyMildew.Landscape — Type
Landscape(host::AbstractMatrix; cellsize)

A regular grid of square cells, cellsize km on a side, with host[i, j] the oak leaf area of cell (i, j) relative to a fully stocked cell (usually between 0 and 1). Cells with host = 0 (open land, sea) carry airborne spores but no disease. The cells with oak, in column-major order, are the model's stands; spatial results are vectors over them, and gridded puts such a vector back on the grid.

source
PowderyMildew.nstands — Function
nstands(land::Landscape)

The number of cells with oak, which are the stands of the spatial model.

source
PowderyMildew.gridded — Function
gridded(land::Landscape, values)

Put a vector over the stands of land (as returned by the spatial accessors) back on the grid, with NaN in cells without oak.

source
PowderyMildew.Dispersal — Type
Dispersal(; rho, ell)

Two-scale conidial dispersal: a share rho of conidia escapes the stand, and travels a typical distance ell (km), the length scale of the screened Poisson field (see dispersal_field). rho = 0 decouples the stands; ell = 0 deposits escaping spores in the cell they came from, weighted by its host density.

source
PowderyMildew.dispersal_field — Function
dispersal_field(land::Landscape, ell, source::AbstractMatrix)

The quasi-steady airborne field φ for a source on the grid of land: the solution of (1 - ℓ² Δ) φ = source with no-flux boundaries, discretised by finite volumes. It conserves the source (sum(φ) ≈ sum(source)) and, in the plane, approaches the kernel K₀(r/ℓ) / (2π ℓ²).

Problem and solution

PowderyMildew.SpatialMildewProblem — Type
SpatialMildewProblem(p::MildewParameters, land::Landscape, dispersal::Dispersal, forcings, C0)

The leaf-level model on every stand of land, coupled by Dispersal, over consecutive seasons. forcings is a SeasonForcing (one season, the same everywhere), a vector of them (one per season, the same everywhere) or a matrix with one row per stand and one column per season, so that phenology and weather can vary in space; all stands share each season's tspan. C0 is the primary inoculum at the start, a number for every stand or a vector with one value per stand. Solve it with solve.

source
PowderyMildew.SpatialMildewSolution — Type
SpatialMildewSolution

The solution of a SpatialMildewProblem: one dense ODE solution per season over all stands. sol(season, t) is the state on day t, a matrix with one column per stand laid out as in MildewSolution. leaf_area, incidence and visible_incidence return one value per stand (gridded maps them back), and regional_incidence the host-weighted mean.

source
PowderyMildew.regional_incidence — Function
regional_incidence(sol::SpatialMildewSolution, season, t; visible = false, latent_visible = 0.0)

The share of all the region's leaves on day t of season that are infected, weighting each stand by its host density; with visible = true, the share with visible mildew as in visible_incidence.
